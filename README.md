# ZoneIQ

A responsive Fortnite storm-planning app built with React and Vite.

## GitHub Pages deployment

In the GitHub repository, open Settings → Pages and select **GitHub Actions** as the source. Pushes to `main` then test, build, and publish the site automatically using `.github/workflows/deploy.yml`. You can also run that workflow manually from the Actions tab.

The deployment builds with the `/Zone-Predicter/` base path. Once the workflow succeeds, the site is available at `https://luke-65786.github.io/Zone-Predicter/`.

## Run

Requires Node.js 22.12+ (Node 24 is supported) and npm.

```sh
npm ci
npm run dev
```

Vite listens on port 5173. Use `npm run build` for the production bundle, `npm run preview` to serve that bundle, and `npm test` for the geometry tests.

## Features

- Place and resize the current circle, choose a phase label, and place your player marker.
- Generate fully nested next-circle scenarios with an adjustable radius ratio.
- Toggle the possible-center area and a direct rotation into the sampled circle.
- Upload a PNG, JPEG, or WebP map screenshot (up to 12 MB). Uploads stay in the browser and are not sent to a server. The full image is fitted inside the map square; crop your screenshot to the map for accurate placement.
- Export the annotated map as an SVG, including an embedded copy of any uploaded map.
- Settings persist in browser local storage. Uploaded images last for the current session only.
- Use the map with a pointer, touch, or arrow keys. Shift + arrow moves in larger steps. Numeric current-circle position controls are under “Fine-tune placement.”

## What the model means

This is a manual practice tool, not a live Fortnite prediction service. The default island is an original illustration, not the current Fortnite map. The app has no match telemetry, secret game data, or server integration.

Each next circle's center is sampled uniformly by area from the disk of radius `currentRadius - nextRadius`. That guarantees that the sampled circle stays inside the current one. The green area shows possible **center locations**, not safe-zone likelihood. Storm phase is a plan label and does not choose game-specific circle sizes. The user sets those sizes manually. Moving endgame zones, terrain, and opponents are not modeled.

The rotation line ends slightly inside the sample circle using a straight-line geometric route. Distances are reported as a percentage of the displayed map width, not in-game meters. Future Fortnite circles are generated by the game server and cannot be inferred reliably from the current circle alone.

## Browser tests

```sh
npx playwright install chromium
npm run test:e2e
```

The browser tests start their own Vite server and use `/usr/bin/chromium` automatically when it is installed. Otherwise install Playwright's Chromium as above. You can choose another installed browser with `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.
